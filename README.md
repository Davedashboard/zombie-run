# Zombie Run

A tower defence game where zombies shamble down woodland trails and you build towers to stop them reaching your cabin.

The whole game is one file, `index.html`, which runs in any modern web browser on a phone, tablet or computer. There's nothing to install.

## Play it

**Online (best for a tablet):** turn on GitHub Pages for this repo (Settings → Pages → Source: *Deploy from a branch* → Branch: `main` / `(root)` → Save). After a minute the game is live at:

https://davedashboard.github.io/zombie-run/

**Install it like an app:** open that link, then:
- **iPhone / iPad (Safari):** tap **Share** (the square with an arrow) → **Add to Home Screen** → **Add**.
- **Android (Chrome):** tap **⋮** → **Install app** (or **Add to Home screen**). Chrome may also pop up an *Install* banner.

It then gets the Zombie Run icon, opens full screen without the browser bars, and works offline after the first launch.

**Offline:** download `index.html` and open it in the tablet's browser. It works without internet. Only the fancy fonts need a connection; without one it falls back to the normal font.

## How to play

- Tap a tower in the tower bar, then tap a glowing spot beside the trail to build it.
- Tap a built tower to upgrade it (up to level 4) or sell it.
- Waves start by themselves on a countdown. Tap the skull by the zombie portal or **▶ Next** to call one early for bonus coins.
- Each zombie that reaches the cabin costs a life. Bosses cost 5.
- **3D** switches to the 3D view: pinch to zoom, drag to move, twist with two fingers to turn. **⟲** resets the camera.
- **1x / 2x / 3x** changes game speed. Works in portrait or landscape.

## What's in it

- **5 worlds, 4 levels each (20 levels):** Space, England, Germany, USSR and China. Each level is harder than the last.
- **9 towers:** Sling Shot, MG52 Gun, Hammer Sword, Flame Thrower, Fart Attack, Tiger Tank, Ray Gun, Blimp Attack and Air Strike.
- **Zombies:** walkers, runners, brutes, and a boss at the end of every world.

Progress (stars and unlocked levels) is saved in the browser on each device.
